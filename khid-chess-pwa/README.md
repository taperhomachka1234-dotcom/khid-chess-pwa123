# Хід

Мобільний PWA для аналізу шахової позиції зі скріншота. Зображення обробляється локально через Canvas, а Stockfish виконується у Web Worker. Після першого повного завантаження додаток працює офлайн із локальною копією рушія.

## Запуск

1. Розпакуй ZIP. Завантаж його вміст зі збереженням підпапок у корінь статичного сайту або підкаталог GitHub Pages чи Vercel.
2. Відкрий адресу сайту через HTTPS. Налаштовувати збірку, серверні маршрути чи заголовки COOP/COEP не потрібно.
3. Для локальної перевірки запусти `python3 -m http.server 8000` у папці з `index.html` і відкрий `http://localhost:8000`.

## Android

Відкрий сайт у Chrome і встанови «Хід» через кнопку в додатку або меню браузера. У галереї чи в системному переглядачі скріншотів вибери **Поділитися → Хід**. Після встановлення Chrome реєструє додаток як одержувача зображень. Файл приймає service worker через `POST multipart/form-data`, тимчасово зберігає локально й видаляє після зчитування.

У звичайній вкладці можна вибрати файл, натиснути **Вставити** або скористатися системною командою вставки зображення. Підтримка конкретного формату, зокрема HEIC, залежить від декодера браузера.

## Розпізнавання й аналіз

- Детектор шукає квадратну сітку за періодичними межами та чергуванням двох кольорів. Підтримує стандартну зелену тему й інші контрастні двоколірні дошки. Якщо автоматична обрізка неточна, натисни **Обрізати вручну**.
- Контури оптимізовані для фігур Chess.com Neo. Помаранчева крапка позначає клітинку, яку варто перевірити. Торкнися клітинки, щоб замінити фігуру або очистити її. **Запам’ятати контур** зберігає локальний зразок вибраної фігури. Для калібрування вибирай повністю видиму фігуру.
- Черга ходу визначається за жовтою підсвіткою, коли вона однозначна. Інакше додаток припускає, що ходить нижня сторона. **Перевернути дошку** змінює відповідність клітинок шаховим координатам на вихідному фото.
- Початкові значення історії FEN — `- - 0 1`. Відомі права рокіровки, клітинку взяття на проході й лічильники можна вказати під пунктом **Історія позиції**.
- Stockfish аналізує до глибини 15 із лімітом до 400 мс. Якщо розпізнавання зайняло більше часу, додаток скорочує бюджет рушія. Виводиться SAN, стрілка та оцінка за білих. Журнал показує час до FEN і до готового ходу. Час на першому запуску та на різних пристроях може відрізнятися.

## Файли

| Файл | Призначення |
| --- | --- |
| `index.html`, `styles.css` | Інтерфейс і темна тема |
| `manifest.json`, `sw.js`, `icons/` | Встановлення PWA, прийом файлів та офлайн-режим |
| `app.js` | Завантаження, вставка, корекція, Canvas і UCI |
| `vision.js`, `neo-profiles.js` | Детекція дошки й контурні профілі Neo |
| `position.js` | Координати, FEN, валідація та шахова нотація |
| `engine-worker.js`, `vendor/` | Stockfish Lite Single і шахові правила |
